# FeatherPad

A quiet place to write, read, and work.

## Write

Use **bold**, *italic*, and `inline code` when they help the reader.

- **Ctrl+Shift+M** switches between reading and synchronized editing.
- **Ctrl+Shift+P** finds any command.
- **Ctrl+Shift+E** exports Markdown to PDF.
- **Ctrl+`** opens the terminal in this file's folder.

## Read

Scroll either pane. The preview and source move together, with one scroll bar on the right.

PDF files open here, with continuous scrolling and an outline.

> Hello, world. Keep the useful words.

```rust
fn main() {
    println!("Hello, FeatherPad!");
}
```
